# Eco-Watch
Overview

Environmental problems such as pollution, illegal dumping and other hazards often go unreported or unresolved because there is no clear channel between residents and the people who can act. EcoWatch gives residents one place to file complaints, and gives administrators a dashboard to manage them by area.

Features
Complaint filing: users submit reports about environmental hazards they observe.
Geolocation: each complaint is tied to a location, so it is clear where the problem is.
Interactive map: complaints are displayed on a map for easy browsing.
Community upvoting: residents can upvote existing complaints, which highlights the issues affecting the most people.
Admin dashboard: administrators review and resolve complaints.
Locality-scoped resolution: each admin sees and handles only the complaints in their own locality.
How It Works
A resident files a complaint describing the hazard and its location.
The complaint appears on the map, where other residents can view it and upvote it.
The administrator for that locality reviews the complaint on the dashboard.
The administrator resolves the complaint and updates its status.
